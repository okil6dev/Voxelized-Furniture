Voxelized Furniture is a mod made by me! that adds detailed 3D furniture to Minecraft

### Main Features

*   **Wireless Light Switches:** Turn on or off any light block within a 20-block radius.
*   **Redstone Showers:** Functional showers powered by redstone signals.
*   **Sittable Chairs:** Sit down on chairs and rotate them by Shift + Right-Clicking.
*   **Working Tech:** TVs and laptops displaying a cool static screen.

### What's Included In The Mod

*   Sittable chairs
*   Cabinets and wardrobes
*   Working TVs and laptops
*   Lights and light switches
*   Redstone-powered showers
*   Decor beds
*   Plants
*   Kitchen furniture, airfryers, toasters and microwave.
*   And more!
